
# منصة أساس - إدارة الجمعيات الخيرية السعودية

## 🎯 نظرة عامة
منصة متكاملة لإدارة الجمعيات الخيرية والأوقاف والمنظمات غير الربحية السعودية، متوافقة مع متطلبات المركز الوطني لتنمية القطاع غير الربحي (NCNP) ومعايير المحاسبة السعودية (SOCPA) وأنظمة هيئة الزكاة والضريبة والجمارك (ZATCA).

---

## 🛠 التقنيات المستخدمة

| المكون | التقنية |
|--------|---------|
| **Frontend** | Next.js 15 (App Router) + React 19 + TypeScript |
| **UI Framework** | Tailwind CSS 4 + shadcn/ui + دعم RTL كامل |
| **Backend** | Next.js API Routes + Server Actions |
| **ORM** | Prisma |
| **قاعدة البيانات** | PostgreSQL |
| **المصادقة** | NextAuth.js + تكامل نفاذ/أبشر |
| **الملفات** | MinIO / AWS S3 |
| **التخزين المؤقت** | Redis |
| **الرسائل** | Bull Queue (بريد إلكتروني/SMS) |
| **النشر** | Docker + Docker Compose |

## 📦 الوحدات والميزات التفصيلية الكاملة

### 1. 📊 لوحة التحكم الرئيسية
- إحصائيات شاملة: تبرعات، أعضاء، متطوعون، مشاريع، مستفيدون، فعاليات
- الحالة المالية الفورية (إيرادات، مصروفات، رصيد)
- رسوم بيانية تفاعلية (خطوط، أعمدة، دوائر)
- مؤشرات الأداء الرئيسية (نظرة عامة)
- آخر الأخبار والإعلانات والتنبيهات
- حالة المشاريع مع نسب الإكمال
- اختصارات سريعة

### 2. 📰 إدارة الأخبار
- إضافة خبر جديد (عنوان، محتوى، صورة، تصنيف)
- عرض جميع الأخبار في واجهة واحدة
- تعديل/حذف وجدولة نشر
- تصنيفات الأخبار

### 3. 📷 مكتبة الصور
- إنشاء ألبومات متعددة
- رفع صور متعددة مرة واحدة
- عرض معرض جذاب
- ترتيب وتنظيم

### 4. 🎬 مكتبة الفيديو
- تصنيفات للفيديوهات
- رفع أو ربط من يوتيوب
- تشغيل داخل المنصة

### 5. 📋 الأنظمة والتعليمات
- إنشاء صفحات محتوى (أنظمة، تعليمات، سياسات)
- محرر نصوص غني
- تصنيفات

### 6. 📢 الإعلانات
- إنشاء وإدارة الإعلانات
- تحديد فترة العرض
- ترتيب وتحديث

### 7. 🏪 المتجر الإلكتروني
- منتجات (اسم، وصف، صور، سعر، كمية)
- سلة تسوق ودفع إلكتروني
- إدارة الطلبات والشحن
- تقارير المبيعات
- ربط مع التبرعات

### 8. 👥 قاعدة بيانات الأعضاء
- تسجيل أعضاء الجمعية
- **سداد العضوية إلكترونياً**
- **متابعة المدفوعات وتاريخ نهاية العضوية**
- **تجديد العضوية إلكترونياً بكل سهولة**
- تصنيفات (مؤسس، فعال، فخري)
- تنبيه قبل انتهاء العضوية عبر SMS

### 9. 🤝 إدارة المتطوعين
- تسجيل وتصنيف المتطوعين
- تتبع المشاركات والأنشطة
- ساعات التطوع وشهادات

### 10. 👨‍👩‍👧‍👦 قاعدة بيانات المستفيدين (جديدة)
- **قاعدة بيانات شاملة لجميع المستفيدين**
- **بيانات تفصيلية عن كل مستفيد**
- **إضافة بأسماء مباشرة أو استيراد من ملف Excel**
- **بوابة المستفيد**: الدخول بحسابه لمتابعة ملفه
- **تعديل بيانات ورفع الأوراق الثبوتية المطلوبة**

### 11. 💰 نظام الفواتير والتبرعات
- **تبرع كزائر بدون تسجيل دخول**
- تبرع مسجل
- **فاتورة إلكترونية تلقائية**: قيمة التبرع + رقم الفاتورة + الرقم الضريبي
- طرق دفع متعددة (مدى، Visa، Apple Pay، STC Pay)
- حملات تبرع مع أهداف مالية
- تبرعات دورية
- إرسال فاتورة إلكترونية لجميع المتبرعين عبر SMS

### 12. 🤲 إدارة المانحين
- قاعدة بيانات المانحين
- إدارة اتصالات وأنشطة المانحين
- تاريخ التبرعات والتفاعل

### 13. 📈 إدارة المشاريع والتبرع الإلكتروني
- **تحديد القيمة المطلوبة لكل مشروع**
- **رسم بياني لنسبة اكتمال المشروع (Progress Bar/Chart)**
- **متابعة المشاريع من لوحة التحكم**
- **إرسال فاتورة إلكترونية للمتبرع على المشروع**
- ربط المشاريع بالتبرعات والمانحين
- حالات المشاريع (مخطط، نشط، مكتمل، متوقف)

### 14. 📅 إدارة الفعاليات
- إنشاء فعاليات (تاريخ، مكان، سعة)
- تتبع الحضور والتسجيل
- تحديث الحالة

### 15. ✅ إدارة المهام (جديدة)
- **إسناد وتكليف وإضافة المهام**
- **متابعة المهام وتحديد الأولويات وتاريخ الاستحقاق**
- **ميزة التعليقات على المهام**
- **إرفاق ملفات في التعليق**
- لوحة مهام (Kanban Board)
- إشعارات للمسؤولين عن المهام

### 16. 📝 الاستبيانات (جديدة)
- **إنشاء استبيانات لجمع المعلومات من المستهدفين**
- أنواع أسئلة متعددة (نص، اختيار، مقاييس)
- **تصدير النتائج إلى Excel و PDF**
